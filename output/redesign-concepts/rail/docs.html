Loops

Use a loop when the same steps run more than once. Choose the loop by asking when you know how many times it runs.

Count-controlled: FOR

Use FOR when the number of repeats is known before the loop starts. The counter moves by 1 unless you add STEP.

times-table.pseudoOpen in editor
DECLARE Count : INTEGER
FOR Count ← 1 TO 5
    OUTPUT Count, " x 7 = ", Count * 7
NEXT Count
1 x 7 = 7   2 x 7 = 14   3 x 7 = 21   …

Which loop to use

LoopUse it when
FOR … NEXTYou know how many times it repeats.
WHILE … ENDWHILEIt may run zero times. The condition is checked first.
REPEAT … UNTILIt must run at least once, such as asking for input.
